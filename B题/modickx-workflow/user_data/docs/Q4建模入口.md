# 问题4 建模入口

Q3 主线已定为 GREEDY_FAST。Q4 当前实现为 `cumulative-optical-v2`，已完成演练闭环及本轮修复；完整状态与结果见 [Q4完成情况与修复-20260911.md](Q4完成情况与修复-20260911.md)。

## 题设增量（相对 Q3）

- 全向 + 定向混合；$N\in[10,16]$、定向个数、朝向 $\psi_i$ 均未知。
- 定向覆盖：朝向两侧各 90°（含），总宽 180°。不是 90° 波束。
- `no_signal` 三分支：无未清除源，或 $d>r_i$，或在定向扇外。Q3 的「无信号 ⇒ 超距」不能原样搬来。
- 光学清除半径 20 m 与射频扇区解耦：扇外仍可能 $d\le 20$ 而清除成功。
- 机器狗可出 $\Omega$（半径 1800 m）；源在圆内。圆外测点对「边缘朝外」定向源有意义。
- 计时、接口、表 1、演练/正式规则同 Q3。Q4 正式另有独立 3 次。

## 可复用

- GREEDY_FAST 在线骨架：七点发现 → 确定清除 / 有限启发式 → SAFE 兜底。
- Q1/Q2 楔形交与二次测向（全向频道仍适用）。
- 已有覆盖定理（`MODELING_REPORT.md` §6）：600 m 网格 $P_4$，81 点，外框 $[-2400,2400]^2$。对任意圆内源点和任意朝向，存在格点在 1000 m 内且严格位于 180° 半平面内部。遍历 81 点不读真值朝向。全向源同时被覆盖。

## 必须新建模的部分

1. **发现覆盖：** Q3 七点对定向不够。主证书应是 $P_4$ 或其经连续位置+全部朝向验证的子集。未验证子集不得替换 81 点。
2. **负观测语义：** `no_signal` 更新扇外/超距并集，不得直接裁掉圆盘。
3. **朝向后验（可选加速，非证书）：** 多次示向 + 无信号可收缩半平面；证书仍靠覆盖点。
4. **SAFE：** 沿 $P_4$ 蛇形 + 频道扫描；未清除频道 81 点全 `no_signal` 才能判无源。
5. **时间：** 81×20 扫描很贵。主线应「证书网格 + GREEDY_FAST 式顺路清除」，而不是一上来走完 81 点。

## 执行边界

- 不启动问题4正式。
- 不把 Q3 七点当 Q4 全清证明。
- 不在歧义 D（未知 $N$ 的终止证据）未写成假设前，用「清了 10 个 / 单点全频道无信号」结束。
- 81 点覆盖证书与 `no_signal` 规则已落实；求解器已实现并完成本轮验证。
