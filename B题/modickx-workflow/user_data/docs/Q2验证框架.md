# Q2 验证框架（正确性优先）

Q2 是有界不确定性模型，不假设方向误差或接收半径的概率分布。验证分三级：

1. **正确性（硬门）**：`z_true ∈ Z_k`；`guaranteed_reception` 必须对所声称的集合成立；`certified_clear` 仅当 `rho(F)≤20`。失败码 `MODEL_OR_IMPLEMENTATION_ERROR`，不得解释为定位效果差。
2. **鲁棒性**：±1° / 5 m / r∈{1000,1500} / C_core 边界；J* 对示向度微扰与方位加密稳定；`F_no ≠ F1 \ B(q,1000)`。
3. **效率**：局部 A/B/C 相对 20–3000 m 旧网格减少候选；相对加密参考集的 J-Gap 可接受。不证明连续全局最优。

实现：`src/q2_validation.py`（真值 oracle 与谓词，不改选点主算法）；`tests/test_q2_invariants.py`、`test_q2_boundaries.py`、`test_q2_robustness.py`、`test_q2_baselines.py`。

建议容差：距离 `1e-8`–`1e-6` m；角度 `1e-10`–`1e-6` °；C_core `1e-6` m；未裁剪扇形 `rho1 ≤ 750.114 + 8` m（外包切线余量）。
