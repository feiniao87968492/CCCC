# Q4 在线状态与 `no_signal` 更新

接口不告诉你该频道是全向还是定向。一次 `direction` 对两类源长得一样。状态里**不要**设「已判定为定向」的真值标签。

## 频道状态

| 字段 | 含义 |
|------|------|
| `unseen` | 尚未在任何 $P_4$ 点测过 |
| `detected` | 至少一次 `direction` 或 `near`（源存在） |
| `cleared` | `/clear` 成功 |
| `certified_absent` | **全部 81 个 $P_4$ 点**对该频道 `no_signal`（命题 3） |

另记：测向历史（点、示向度）、已访问的 $P_4$ 下标。Q3 的七点 $P_3$ 不能写入 `certified_absent`。

## `/measure` 三值（Q4）

覆盖：源在 $g$，检测点 $s$。全向：$\|s-g\|\le r_i$。定向：$\|s-g\|\le r_i$ 且 $d\cdot(s-g)\ge 0$（两侧各 90°，含边界）。示向度是 $s\to g$，与「源→检测点」差 180°。

| 结果 | 可写入信念的 |
|------|----------------|
| `direction` | 该频道有未清除源；$s$ 在射频覆盖内；位置落在以 $s$ 为顶点、示向度 $\pm 1^\circ$ 的楔内。与 Q3 相同，可做交会。 |
| `near` | 有源且 $\|s-g\|\le 5$，且在射频覆盖内。原地 `/clear`。 |
| `no_signal` | **三分支并集**：该频道无未清除源，或超距 $d>r_i$，或定向扇外。 |

## 禁止的推理

1. 把 Q3 规则「已确认有源 + `no_signal` ⇒ $d>1000$」用在类型未知时。定向源可以就在附近、背向 $s$。
2. 用 `no_signal` 从可行域里挖掉整个 1000 m 圆盘。
3. 因 `no_signal` 放弃光学清除：$\|s-g\|\le 20$ 时 `/clear` 仍可能成功，与朝向无关。
4. 单点全频道无信号 ⇒ 全局无源。

## 允许的推理

- **源尚未确认存在**（一直 `no_signal`）：只减少「尚未覆盖的 $P_4$ 点」。点集扫完 → `certified_absent`。
- **源已确认存在**（有过 `direction`/`near`）后又 `no_signal`：楔形可行域 $F$ 仍在；本测点 $s$ 不能当作「$F$ 里没有点」，只能当作「$s$ 此刻不在射频覆盖里」。后续仍可对 $F$ 做二次测向或光学试清。
- **两次 `direction`：** 与 Q3 一样交会。定向源只要两次都在扇内，楔交合法。
- **失败 `/clear`：** 不能断言该频道无源。

## 与 GREEDY_FAST 的接口

已有 `direction` 的频道：位置信念按 Q3 楔交走 FAST 的确定清除 / 有限启发式。  
尚无 `direction` 的频道：只通过访问未测过的 $P_4$ 点发现，不得提前判空。
