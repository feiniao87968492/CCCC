冻结/演练入口：`TRI25`（25 点连续发现证书，最大距离 943.01 m，凸包余量 17.75 m）+ `ROUTE_ADAPTIVE_V4`。实现：`src/q4_cover.py`、`src/q4_policy.py`、`simulator_automation/q4_practice.py`。N=16 计数判空与几何证书独立；`no_signal` 不是 `d>1000`。

- 局部轮固定全域规则与外圈 1950 m，改局部探测预算、短程续作和清除选择。LPC = L30 + P1 + C15。

SQUARE81 仍是完备回归证书；HEX37 是中间覆盖。当前默认不是 81 点蛇形。
