# 题面与任务分析

执行策略 legacy，稿件 competition。题面、附件为最高权威，user_data/B题-统一建模口径.md 收口定义，parameters.csv 冻结28项常数。逐句翻译复用既有104单元台账，不声称重新调用翻译器。A-D 已由本轮用户确认，见 SEMANTIC_DECISIONS.md；不授权正式测试。

Q1 给出角锥交集直径的一般算法及直径圆不能普遍覆盖区域的反例。稳妥路径为半平面交与凸集极点距离；空集、点、线段、无界交集须分别返回状态。纯交会与物理可行域不同，禁止默认用任意大方框把无界问题变为有限问题。

Q2 输出仅依赖首测可见信息的第二点候选区域及选择策略。采用最坏点误差，直径作对照，20米最大距离为清除充分条件；移动时间独立权衡。需显式保留第二点无信号分支，不能按真位置排点。直角交会仅是候选设计动机，不是未知位置下已证最优结论。

Q3 全向源在线搜索、定位、清除，硬目标全部清除，之后优化总虚拟时间。基线拟采用覆盖搜索加集合定位；覆盖证书、定位收缩及时间可行性尚需证明。Q4 混合源还需朝向未知的覆盖证据；不能把无信号等价为距离过远。方向盲区、边缘外向源和预算耗尽是关键失败条件。

语义身份：会话+request_id 标识动作，源以会话+频道标识；相同频道跨会话不是同一源。独立统计单位为生成案例，不是动作行。两次 smoke 不是策略评估样本；同点同频道为重复测量而非独立角度样本。

全清除事件在正式测试中因 N 不可观测而不能直接由 K 验证；无证书终止记 unresolved，预算截断的完成时间记 right-censored。连续搜索域包括机器狗合法坐标盒，源限1800米圆域；具体算法计算域是后续模型选择，不能当题设边界。

模拟器输出只用合法请求反馈。隐藏源坐标、半径、朝向、未结束时的N均不进入策略。K=0时平均时间留空。现有12条动作无清除成功，不支持任何清除率或优化优势。资料审查仍需在几何实现前回看PDF位图；论文前逐条核验文献，不将 papers 中全部条目视为已验证引用。
