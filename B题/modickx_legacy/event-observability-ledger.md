# 事件可观测性

observed：accepted动作、direction/near/no_signal、清除成功、虚拟时钟。
unresolved：正式测试N不可观测，无逐频道证书时不能证明K=N。演练结束获得N后才计算K/N，当前smoke不具备策略成绩意义。
right-censored：预算或窗口耗尽前未完成任务，完成时间是右删失值，不能当成成功完成时间参与均值。
scenario extrapolation：未来离线随机场景仅说明该生成机制下表现，不冒充官方正式结果。
终止阈值：near为5米含边界，清除为20米含边界；全清除需逐频道成功或严密排除证书。D为已确认的证据要求，不是已证明的算法能力。
