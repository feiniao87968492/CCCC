# Q4 局部决策消融

本轮按“重局部策略、轻全域路线”的要求，保持新策略的TRI25外圈1950 m和
冻结V4全域规划规则，优化局部探测、短程续作和清除选择。局部选择会改变实际路线，
但没有另换全域路径算法。上一轮JSO+紧凑外圈+D-optimal仅作附加对照。

## 主实验结果

16组×400场共6400次运行，每组5208个源全部清除并完成场景认证。
本轮新局部候选中，**LPC=L30+P1+C15**的平均T/K最低；全部16组中，上一轮方案同场重跑均值仍略低。

| 策略 | 平均T/K（s/源） | 平均行走（s/场） | 平均探测（次/场） |
|---|---:|---:|---:|
| 冻结V4同场重跑 | 537.38 | 4985.09 | 295.55 |
| 上一轮JSO+紧凑外圈+D-optimal | 513.49 | 4704.63 | 290.07 |
| C15 | 526.19 | 4848.50 | 289.30 |
| LC | 519.90 | 4781.42 | 285.10 |
| PC | 519.92 | 4750.37 | 290.70 |
| **LPC** | **515.62** | **4718.75** | **286.00** |

相对冻结算法，LPC平均T/K降低4.049%、行走降低5.343%、探测降低3.231%，
五类场景均值均改善，其中边界组改善5.339%。平均配对差为−21.758 s/源，
95%种子块区间[−26.137, −17.520]。仍有92/400场退化，最差+84.942 s/源。
上一轮方案边界组退化0.697%；LPC与上一轮方案的总体均值差为+2.129 s/源，
区间[−2.126, +6.661]跨零，不能宣称总体胜出。

综合局部效率优先选LPC；少探测优先可保留LC。LC加入P1后每源再快4.279 s，
但每场多测0.898次。小幅修改可选C15：平均T/K降低2.082%，379胜/21负，
最差退化26.940 s/源。P1/P2仅比S_all少测，仍比冻结V4多测；P1对S_all的耗时差尚不明确。
F60/F120和M50/M75未取得平均T/K收益，均保留在完整表中。

验证完成：290项测试通过；6400条轨迹、2,008,468个测量/清除操作全量审计通过；
独立开发及主实验审查均为PASS_WITH_WARNINGS。独立复核覆盖20,810个预算探测关联、
5,605个连续处理步骤、4,461次质量试清除规则，并抽查133次质量评分和2,061次光学成本。
抽查复用了生产正观测多边形和光学格；这不等于完全独立的几何求解器验证。
最终分析/审查源码及哈希见final_sources/和evidence_manifest.json；各批仿真快照仍以原manifest为准。

## 五类局部策略

| 代号 | 局部决策 | 微调 |
|---|---|---|
| L | 探测点按“走到探测点、再接近源、尚未完成定位”的局部代价排序 | 未完成惩罚30/90 s |
| P | 在S准入门槛内，按预期信息收益和实际换频代价选择有限补测 | 每站1/2次；另设无限单站预算S_all对照 |
| F | 连续完成当前源的短距离动作，遇无信号或清除失败停止 | 距离60/120 m，最多2个追加决策 |
| C | 比较完整光学覆盖与“再测一次后清除”的规划代价 | 光学/探测代价比≤1.0/1.5；早期覆盖≤12格 |
| M | 选择20 m清除圆内后验空间质量最大的点试清除 | 质量门槛0.50/0.75；每源最多2次，新正观测前不重试 |

开发集选出的三个组合：LC=L30+C15，PC=P1+C15，LPC=L30+P1+C15。
所有初始策略都进入主实验，包括开发集中变慢或未改变实际操作的策略。

P的预算跨同站回调共享，只有已接受操作的单段移动>1 m才重置；未知频道认证扫描不计入此预算。
F的“2次”指追加决策，一次近距离测量可立即带来一次清除；审计会分别记录决策与物理操作。
C的RF一测成本和L的定位完成率是启发式代理，不是保证或全局最优解。
M的后验质量不等于校准成功概率，光学清除不要求RF接收。负RF会更新软权重，
但不裁剪正观测可行多边形，也不重置M重试版本。清除失败照常计时。

## 配对设计

开发集40设置为40000–40029混合endpoint30场，加40000–40009边界外向10场。
初始13×40=520次，新增组合及基线4×40=160次。
主实验锁定16×400=6400次，种子50000–50199：混合endpoint200场，
全定向、全向、边界外向最小半径、混合smooth各50场，共200个独立种子块。

所有差值与本次同场重跑冻结算法配对；上一轮514 s和早期冻结517 s的旧均值
不作为新场景分母。区间按种子块bootstrap计算，保留每块所有场景并按设置等权。
报告mean(T/K)和sum(T)/sum(K)、行走、探测拆分、换频、失败清除、机制计数、
配对胜负、p95、最差退化、各类型与源数分层。失败行不删除。
