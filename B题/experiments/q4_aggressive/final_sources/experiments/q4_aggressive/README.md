# Q4 激进局部策略消融

本轮以一般场景的 **mean(T/K)** 最低为目标。每组必须在所有一般及压力
场景中全清并完成频道认证，才有排名资格。行走时间、探测次数、失败试清除
用于解释耗时，允许单项增加。冻结 TRI25/V4 基线保持不变。

## 六类策略与组合

全部新策略继承 LC 的局部候选 L30 与光学成本门槛 C15；全域路线固定 tour，
覆盖半径固定 1950。E 替换 C15，其他机制按 design.md 的优先级叠加。

|方向|参数|实验含义|
|---|---|---|
|E 预期成本光学清除|比值 1 / 2|按空间权重及行走成本排序完整覆盖，预期成本较低时提早清除|
|B 两步局部测点|偏移 20 / 60 m|比较当前移动及第二步完成成本，增加近距离候选|
|G 动态补测|收益门槛 0.75 / 1.5|在实际停点按预计节省行走与探测代价选频道，每站最多 3 次|
|R 提前结束专用探测|2 / 4 次|已有两条测向且区域较小时转完整光学覆盖|
|H 宽门槛乐观清除|半径 200 / 400 m|放宽 Q3 两测向最小二乘试清除，但限制病态交会与重试|
|N 路过试清除|空间质量 0.20 / 0.50|当前位置满足条件就试清除，额外行走为零|
|组合|GR、GN、GRN|仅由修正后的开发集按预先规则选出的 G075、R2、N20 叠加|

## 主实验结果与后续投入方向

19 组 × 400 场已完成：每组 5275/5275 个源全清，全部频道认证通过。
一般场景 350 场是首要排名口径，包含 4611 个源；全场景与压力组单独报告。
本轮最有继续优化前景的是 **G 动态补测**。新局部候选最佳 G15（门槛 1.5）
一般 T/K 为 **489.643 s/源**，比同场冻结基线 513.190 低 **4.588%**。
所有新候选都以 LC 为底座，判断新机制是否有效应看相对 LC 的差值：

|方向/方案|一般 T/K (s/源)|相对 LC (s/源)|判断|
|---|---:|---:|---|
|LC 对照|496.926|0|本轮机制增益的直接参照|
|G15 动态补测|**489.643**|**−7.284**|优先投入；配对区间 [−10.601, −4.122]|
|G075 动态补测|490.442|−6.484|同方向有效，两个门槛的差异区间跨零|
|R2 提早转光学|496.199|−0.727|次优先，收益小，差异区间跨零|
|R4 提早转光学|496.773|−0.154|收益很小，23/350 场实际提前转光学|
|N50 路过试清除|496.905|−0.021|低优先级，绝对收益极小|
|H200 宽门槛乐观清除|497.804|+0.878|未获得平均收益；H400 更差|
|B20 两步候选|500.299|+3.373|当前代价近似未转化为实际收益|
|E1 预期光学成本|500.603|+3.677|探测减少，但行走增加抵消了收益|
|G075+R2|490.427|−6.499|相对 G075 只改善 0.015，叠加增益未确立|
|G075+N20|490.461|−6.465|比 G075 慢 0.019|
|G075+R2+N20|490.447|−6.479|比 G075+R2 慢 0.020|

G15 对比 LC 每场行走减少约 105.70 秒，探测增加 0.163 次。按每源分解，
行走节省 8.107 秒，测量/切频/试清除净增加 0.824 秒，净降 T/K 7.284 秒。
相对冻结基线，行走下降 5.953%、探测下降 3.943%；相对 LC 的探测并未减少。
G15 相对 LPC 的 T/K 差为 −6.242，描述性配对区间 [−9.586, −3.094]。

旧 JSO_compact_dopt 对照仍是**一般场景观测均值最低**，为 488.847；G15 比它
慢 0.796 秒/源，差异区间 [−2.826, 4.396]，未区分出唯一赢家。全 400 场中，
G15 为 496.695，旧对照为 501.496；边界 50 场分别为 546.065、590.043。
按照用户明确的一般场景 T/K 优先，不能用全场景结果宣称 G15 已击败旧方案。
G15 在五类场景中均优于 LC 的均值，但一般场景仍有 90/350 场慢于冻结基线，
最差增加 102.275 秒/源；不存在逐场一致优势。

后续建议首先细化 G 的局部收益门槛和每停点预算，以“补测后实际节省的 T/K”
校准价值；其次研究 R 的自适应退出门槛。还可将 G 接到旧 JSO 对照上单独检验，
但这组交互**本轮没有测试**，不能把二者现有收益直接相加。当前证据不支持继续
盲目扩大 H 半径、提前大量光学清除或堆叠 N。新增实验应再使用新种子；本轮
主实验结果仅用于结论与提出下一轮假设，未据此重新选择组合。

这里 LC/LPC/旧 JSO/模块交互区间为描述性边际区间，未校正这一整套探索性
比较的多重选择；相对冻结基线的主比较另报告 Holm 校正。结论范围为本批
离线分布，独立审查详见 `reviews/primary-validation.md`。

## 数据与复现

有效初始开发集 `dev_valid40`：16 组 × 40 场，20 个种子块，种子 60000 起。
有效组合开发集 `dev_combinations40`：10 组 × 40 场，含 4 个对照和 3 个单项。
主实验 `primary_valid400`：19 组 × 400 场，200 个种子块，种子 70000 起。
一般场景 350 场，边界外向最小半径压力场景 50 场。每个设置等权计算 T/K，
同种子的多个设置共同重采样构造配对区间。

在 B题 目录运行，输出目录须不存在。以下使用新目录，避免覆盖证据：

```powershell
python experiments/q4_aggressive/run_aggressive.py --suite dev --variants baseline,LC,LPC,previous_best,E1,E2,B20,B60,G075,G15,R2,R4,H200,H400,N20,N50 --output experiments/q4_aggressive/replay_dev40 --workers 12
python experiments/q4_aggressive/run_aggressive.py --suite primary --output experiments/q4_aggressive/replay_primary400 --workers 12
python experiments/q4_aggressive/audit_aggressive.py experiments/q4_aggressive/replay_primary400
python experiments/q4_aggressive/summary_aggressive.py experiments/q4_aggressive/replay_primary400
python experiments/q4_aggressive/analyze_results.py experiments/q4_aggressive/replay_primary400
```

`selection.json` 是已经冻结的组合选择，不因复跑主实验而重选。
初始及组合开发的 280 条重复轨迹逐事件哈希一致。逐场 CSV、完整压缩事件、
真值与计费审计、运行前源码快照均保留。统计脚本必须读取与结果哈希一致的
完整审计，才能出表。图表同时输出 PNG、PDF、同名 CSV 与元信息。
